## 0. 결론

- **개인 노트북 → FMTC 노트북으로 이전.** ROS2 Humble·의존성은 이미 있었고 `colcon build` 그대로 됨. `sign_detect`는 GPU(CUDA)로 돌아 CPU 때의 1~3초 멈춤이 없어짐.
- **코스: 2차선 장애물 → 1차선 장애물(바로 앞에 신호등).** 2차선이 주행 차선, 1차선은 추월 차선 → `obs_evade`는 `mode: return`(지나치면 2차선 복귀).
- **신호등 정지선이 없는 코스 → `stop_line_mode: false`(신호등만 보고 정지).** 빨간불이 장애물 회피보다 우선하도록 `decision_auto` 순서를 바꿈. 노란불에서 정지가 풀리던 것 수정.
- 남은 문제: **밤(18시 이후)에는 신호등 몸체가 어두운 배경에 묻혀 YOLO가 못 잡음**, `obs_evade`가 수동 조작을 모름(주행마다 재시작), 라이다 비상 정지 없음. → 5장.

## 3. 설정 변경 (`front_1019.yaml`)

| 값 | 전 → 후 | 근거 |
|---|---|---|
| `decision_auto.stop_line_mode` | true → **false** | 이 코스는 신호등 앞 정지선 없음(정지선 y 최대 184~250, 기준 285에 못 미침) |
| `sign_detect.min_bbox_size` | 2000 → **10000** | 2000이면 첫 장애물 지나자마자 멀리서 섬(빨강 6200~7500). 원하는 위치(두 번째 장애물 피하는 중간)에서 10000~18000 |
| `obs_evade.side_require_seen` | false → **true** | false면 옆이 0.5초만 비어도 복귀 → 아직 앞오른쪽에 있는 장애물 쪽으로 돌아갈 수 있음 |
| `obs_evade.pass_timeout_s` | 10.0(코드 기본) → **3.0** | 옆에서 끝내 못 본 경우의 복귀 대기. 추정치 |
| `obs_evade.mode` | return (그대로) | 하루 중 toggle도 시험했으나 "2차선 = 주행 차선" 규칙에는 return이 맞음 |

## 5. 남은 일

1. **밤 신호등 인식**: 경기장 조명에서 다시 확인. 필요하면 색 기반 보조(이미 본 빨간불 유지용) 또는 밤 사진으로 재학습.
2. **차선 상태 초기화**: 지금은 주행마다 `obs_evade` 재시작(`start_lane`). Y로 2차선 초기화 또는 카메라로 실선·점선을 봐서 차선 판별.
3. **라이다 비상 정지**: 정면 가까이에 물체가 있으면 무조건 정지(차 폭 기준 구역). 회피 중 최소 0.43 m 사례가 있어 구역 폭을 차 폭에 맞춰야 함.
4. **복귀 오른쪽 과조향**: 지금은 주행상 문제없어 보이나 여유가 작음(기둥 0.5~0.8 m). 필요하면 1차선 최소 체류 시간.
5. 신호등이 복귀 중 화면 왼쪽으로 빠짐 → 신호등 카메라를 약간 왼쪽으로.
