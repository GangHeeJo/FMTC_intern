→ 이 시점 결론: "좌회전"은 `LANE2` 상태에서 1차선 물체를 정면 장애물로 잡은 것. 원인 후보 ① 복귀가 덜 된 채 `LANE2`, ② 2차선 왼쪽 치우침.

## 5. "2차선 = 주행 차선" 규칙과 return 보강 (17:30 ~ 17:50)

사용자: 1차선은 추월 차선이라 장애물을 지나면 1차선에 장애물이 없어도 2차선으로 돌아와야 함 → **return이 맞음.**

대화로 정리한 것
- toggle vs return: 차이는 피한 뒤 머무는 차선. toggle은 덜 다듬어짐(위 버그, 1→2 때 옆 확인 없음).
- 차선을 정확히 알면 "재시작 필요"·"상태 어긋남"은 풀리지만 가짜 장애물(기둥)·옆 차선 점유는 따로 봐야 함.
- 카메라로 실선·점선 판별: 방식 2에 덩어리 분류 코드가 있으나 한쪽만, 10/17 카메라 기준. 지금(방식 3, 정면)에는 **없는 기능**.
- 보편적 구성: 2차선 고정 출발 + 동작으로 상태 추적 + 초기화 수단 / 나갔다가 지나치면 복귀 / 바꾸기 전 대상 차선 확인 / 우선순위 비상정지 > 신호 > 추월 > 차선 / 감지 구역은 차선 폭. 지금 없는 것: 비상 정지, 진입 시 왼쪽 확인, 초기화 버튼.
- 비상 정지는 라이다로(거리 직접 측정). 구역은 차 폭/2 + 여유(±0.4 m면 정상 회피 중 0.43 m에서도 걸림), 차체 점 제외, 연속 스캔·해제 지연, `decision_auto` 최상위, 자동 모드에서만.

return 문제 두 가지를 고침(58b3ad0)
1. `side_require_seen: false`면 옆이 0.5초만 비어도 복귀 → `true` + `pass_timeout_s: 3.0`. 그런데 옆 확인이 `LANE1`에서만이면 변경 **중에** 지나친 장애물을 못 봐 매번 3초 기다림 → `TO_LANE1`부터 보고 `LANE1`로 넘어가도 유지.
2. "양쪽 막힘" 정지가 앞 장애물이 1.3 m 안쪽으로 오면 풀림 → 0.3 m~까지 앞으로 보고 앞이 빌 때까지 유지.
