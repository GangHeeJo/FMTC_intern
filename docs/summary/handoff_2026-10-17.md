# 10/17 인수인계 — 장애물 차선 변경 완성 (먼저 이것만 읽으세요)

> 상세 기록(시험 22번, 원인·조치): [docs/records/field_notes_2026-10-17.md](../records/field_notes_2026-10-17.md). 연결 방법은 [10/11 인수인계](handoff_2026-10-11.md) 그대로입니다.

작성: 도경윤. 브랜치 `gyungyoon`. 차선 카메라 320×240.

## 무엇이 되나

- **장애물 2개 차선 변경 전체 순서**: 2차선 → (장애물) → 1차선 → (장애물) → 2차선 → 계속 주행. 2차선 출발·1차선 출발 둘 다 실차 성공.
- 1·2차선 추종: 새 **모양 기반 검출**(흰 덩어리 굵기·길이·모양으로 점선/실선/주차선/흰 차 구분). 1차선 점선 검출 40~60% → 98~100%.
- **신호등 감지 실차 검증 완료**: 빨간불에서 정지, 신호가 바뀌면 재출발. 횡단보도 정지도 확인.

## 실행

```bash
# 1
ros2 launch s1_stack s1_stack.launch.py
v4l2-ctl -d /dev/cam_lane -c brightness=128 -c exposure_dynamic_framerate=0
v4l2-ctl -d /dev/cam_front -c exposure_dynamic_framerate=0
# 2
OMP_NUM_THREADS=6 taskset -c 6-11 ros2 run sign_detect sign_detect --ros-args -p model_path:=$HOME/FMTC_intern/sign_detect/best_0808.pt
# 3
taskset -c 0-5 ros2 run lane_trace lane_trace --ros-args --params-file ~/FMTC_intern/s1_stack/config/obstacle_1017.yaml
# 4 (차를 출발 위치에 놓은 뒤, 시험마다 새로)
taskset -c 0-5 ros2 run obs_evade obs_evade --ros-args --params-file ~/FMTC_intern/s1_stack/config/obstacle_1017.yaml -p start_lane:=2
```

- 조이스틱: **A 자동, B 수동, Y 정지** (X 아님).
- `sign_detect`가 1~3초씩 멈춰 차가 서다 가다 할 수 있음 → 장애물 시험 땐 `decision_auto`를 `-p require_signals:=false`로 다시 띄움(상세 기록 3장).
- 노트북 디스크(49GB)가 bag로 금방 참 → 녹화 전 오래된 bag 정리.

## 주의

- **밤 조명에서는 흰 선 검출이 떨어짐**(흰색이 푸르스름/신호등 근처 붉게 찍힘). 낮에 시험할 것. `s_max` 30으로 일부 보완.
- Arduino **A4(조향 각도 센서)·8번 선** 접촉 불량이 이틀 연속 → 바퀴가 혼자 움직이면 이 선부터 확인.
- 출발 차선 자동 판단(`start_lane:=0`)은 상자 옆 2차선 구간에서 틀림 → 지금은 1/2로 직접 지정.
