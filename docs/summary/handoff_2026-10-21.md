# 10/21 인수인계 — FMTC 노트북 이전, 신호등만 보는 정지 (먼저 이것만 읽으세요)

> 상세 기록: [docs/records/field_notes_2026-10-21.md](../records/field_notes_2026-10-21.md).

작성: GangHeeJo(실차) / Claude(분석·코드). 브랜치 `main`. FMTC 노트북(10코어, RTX 4060).

## 무엇이 되나

- **2차선 장애물 → 1차선 장애물 코스**: 2차선 장애물을 1차선으로 피한 뒤, 지나치면 2차선으로 복귀(`mode: return`).
- **신호등만 보고 정지**(`stop_line_mode: false`): 빨간·노란불이면 차선 변경 중이라도 정지하고, 변경 동작은 멈췄다가 초록불에 이어서 함. 노란불로 바뀌어도 정지 유지.
- `sign_detect`는 GPU로 실행(CPU 때의 1~3초 멈춤 없음).

## 실행

```bash
# 1 (decision_auto는 front_1019.yaml로 같이 켜짐)
ros2 launch s1_stack s1_stack.launch.py
# 2
OMP_NUM_THREADS=4 taskset -c 6-9 ros2 run sign_detect sign_detect --ros-args --params-file ~/FMTC_intern/s1_stack/config/front_1019.yaml
# 3
taskset -c 0-5 ros2 run lane_trace lane_trace --ros-args --params-file ~/FMTC_intern/s1_stack/config/front_1019.yaml
# 4 (차를 2차선 출발 위치에 놓은 뒤, 주행마다 새로. 1차선에서 시작하면 -p start_lane:=1)
taskset -c 0-5 ros2 run obs_evade obs_evade --ros-args --params-file ~/FMTC_intern/s1_stack/config/front_1019.yaml
```

- 조이스틱: **A 자동, B 수동, Y 정지**. 수동: 왼쪽 스틱 위아래 = 속도, 오른쪽 스틱 좌우 = 조향. 처음엔 정지 모드.
- 녹화(영상 빼고):
  ```bash
  cd ~/bags && ros2 bag record -o obs_$(date +%H%M%S) /scan /rosout /cmd_lane /cmd_obs /cmd_auto /cmd_out /drive_mode /lane_lines /lane_detected /lane_slope /lane_changing /lane_change_flag /lane_mirror /stop_line_y /crosswalk_active /light_stop /light_green
  ```
  신호등 카메라를 보려면 `/cam_front/image_raw/compressed`, 차선 카메라를 보려면 `/cam_lane/image_raw`(1분 약 420 MB) 추가.

## 주의

- **`sign_detect`도 `--params-file`을 꼭 줄 것.** 빠지면 `min_bbox_size` 15500(기본값)이라 빨간불을 거의 인정 안 함.
- **`obs_evade`는 수동 조작을 모름.** 조이스틱으로 차를 옮긴 뒤 자동으로 이어 달리면 차선 상태가 어긋나 엉뚱한 쪽으로 피함 → 주행마다 재시작.
- **노트북 화면이 차선 카메라를 가리지 않게** 놓을 것(17인치라 시야에 들어옴).
- **밤(해 진 뒤)에는 신호등 인식이 안 될 수 있음.** 경기장 조명에서 `min_bbox_size`(정지 위치)와 함께 다시 확인.
